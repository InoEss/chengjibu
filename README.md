# 成绩簿 · 高中成绩记录（PWA）

纯本地、离线、单人使用的高中成绩记录应用。记录每次考试分数与排名、看趋势、对照目标，所有分析由本地规则计算。

## 部署要求

把本目录作为静态站点根目录，使用 HTTPS：

- `index.html`：应用本体（单文件内联 CSS/JS）
- `manifest.json`：PWA 名称、图标、启动方式
- `sw.js`：离线缓存；必须与 `index.html` 同目录
- `icons/`：应用图标
- `.nojekyll`：GitHub Pages 用，避免 Jekyll 处理

不要把 `sw.js` 改名或移到子目录；`manifest.json` 的 `start_url` / `scope` 是相对路径 `./`，所以站点可以放在子目录（例如 GitHub Pages 的 `/chengjibu/`）。

## 安装到桌面

- **Android Chrome**：打开链接 → 三点菜单 → 安装应用 / 添加到主屏幕。
- **iPhone Safari**：打开链接 → 分享按钮 → 添加到主屏幕 → 添加。
- 也可以在应用「设置 → 安装到桌面」里看步骤。

第一次打开需要联网加载；之后缓存可用，断网也能打开。数据只保存在当前设备，没有账号、没有云同步。

## 数据

- localStorage 键：`chengjibu.data.v1`
- 明文 JSON，可在「设置 → 查看本地 JSON」直接读
- 「导出备份」得到 `成绩簿备份_日期.json`
- 换机：旧设备导出 → 新设备「从文件恢复」→ 校验预览 → 覆盖导入

电脑和手机的数据各自独立；部署站点本身是公开代码，不包含任何成绩数据。
